# 🚗 VIN Inspector — Telegram Bot

Асинхронный Telegram-бот на **Python 3.12** и **aiogram 3.x**, выступающий клиентом для локального бэкенда **VIN Inspector** (PHP / NHTSA / каталоги запчастей).

---

## 🌟 Возможности бота

1. **Декодирование VIN-кода:**
   - Строгая валидация формата по стандарту **ISO 3779** (17 символов, проверка отсутствия букв `I`, `O`, `Q`).
   - Получение данных через локальный эндпоинт `GET /api/decode-vin.php?vin=...`.
   - Вывод стильной карточки автомобиля (Марка, Модель, Год выпуска, Страна сборки, тип кузова/двигателя, ссылка на оригинальный каталог бренда).
   - Интерактивные кнопки под карточкой: `🔍 Проверить запчасть по OEM` и `🚗 Другой VIN`.

2. **Проверка совместимости запчастей по артикулу (OEM) с машиной состояний (FSM):**
   - Переход в контекст проверки запчасти для ранее декодированного автомобиля.
   - Запрос к эндпоинту `GET /api/check-oem.php?oem={OEM}&brand={brand}&vin={vin}`.
   - Определение совместимости (`fit` / `not-fit`), вывод наименования детали, комментария каталога и прямой ссылки на деталь в каталоге бренда.
   - Возможность сразу проверить другой номер или ввести новый VIN.

3. **Надёжная обработка ошибок:**
   - Проверка доступности бэкенда с понятными сообщениями при сбоях сети или таймаутах.
   - Дружелюбные подсказки при опечатках в VIN или отсутствии детали в каталоге.

## 🚀 Установка и запуск

### 1. Предварительные требования

- **Python 3.12** (управляется через `uv`)
- Запущенный локальный PHP-бэкенд на `http://localhost:8000/`:
  - `GET http://localhost:8000/api/decode-vin.php?vin={VIN}`
  - `GET http://localhost:8000/api/check-oem.php?oem={OEM}&brand={brand}&vin={vin}`

### 2. Настройка конфигурации

Откройте файл `.env` в корне проекта и укажите ваш токен бота (полученный у [@BotFather](https://t.me/BotFather)):

```dotenv
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
BACKEND_URL=http://localhost:8000
REQUEST_TIMEOUT=15
```

### 3. Запуск бота через uv

Для запуска бота выполните команду в терминале:

```powershell
uv run bot.py
```

Или при явном указании пути к `uv`:

```powershell
& "C:\Users\User\.local\bin\uv.exe" run bot.py
```

Либо активируйте виртуальное окружение:

```powershell
.venv\Scripts\activate
python bot.py
```

## 🧪 Тестирование бота

1. Отправьте боту команду `/start`.
2. Отправьте тестовый VIN (например, `WAUZZZ8K9BA123456`).
3. Бот пришлёт карточку автомобиля Audi с кнопками действий.
4. Нажмите **«🔍 Проверить запчасть по OEM»** и отправьте артикул `06E115562A`.
5. Бот проверит совместимость детали с автомобилем и отобразит статус проверки и ссылку на каталог.
